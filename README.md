# ai_lab4
# Обработка производственных журналов

## Описание проекта

Проект предназначен для объединения, очистки и анализа данных из трёх производственных журналов за апрель: утренней, дневной и ночной смен.

Исходные файлы отличаются названиями столбцов, форматами дат, числовыми значениями и обозначениями категориальных признаков. В рамках проекта данные приводятся к единому формату, проверяются на наличие ошибок и дубликатов, после чего формируются итоговая таблица и отчёт о качестве данных.

## Используемые технологии

- Python
- Jupyter Notebook — пошаговое выполнение и документирование анализа
- Pandas — обработка и анализ табличных данных
- NumPy — работа с числовыми данными и условиями

## Входные данные

Проект использует три исходных CSV-файла:

| Файл | Описание | Разделитель |
|---|---|---|
| `shift_morning_raw.csv` | Журнал утренней смены | `;` |
| `shift_day_raw.csv` | Журнал дневной смены | `;` |
| `shift_night_raw.csv` | Журнал ночной смены | `,` |

Всего в исходных журналах содержится 159 записей.

## Этапы обработки данных

1. **Загрузка данных.** Чтение трёх CSV-файлов с учётом различных разделителей.
2. **Унификация структуры.** Переименование столбцов к единой схеме.
3. **Нормализация значений.** Приведение названий смен, продуктов и статусов качества к единому справочнику.
4. **Очистка данных.** Преобразование дат и числовых значений, нормализация идентификаторов партий.
5. **Поиск дубликатов.** Выявление повторяющихся записей и удаление повторных вхождений.
6. **Проверка качества.** Выявление подозрительных значений: отрицательного количества брака, превышения брака над выпуском, аномально большого выпуска, отсутствия данных о выпуске, температуры выше допустимого порога и неизвестных статусов качества.
7. **Разделение данных.** Корректные записи сохраняются в итоговой таблице, подозрительные переносятся в отдельный файл с исходными строками.
8. **Расчёт показателей.** Вычисление доли брака, количества годной продукции и статуса температурного режима.
9. **Формирование отчёта.** Создание сводного отчёта о найденных проблемах качества данных.

## Выходные файлы

| Файл | Содержание |
|---|---|
| `factory.csv` | Очищенная и унифицированная таблица производственных данных |
| `suspicious_rows.csv` | Исходные строки, содержащие подозрительные значения |
| `data_quality_report.csv` | Отчёт о найденных проблемах и принятых действиях |

### Дополнительные расчётные показатели

- `defect_rate` — доля брака: отношение количества бракованных единиц к общему выпуску.
- `good_units` — количество годной продукции: разница между выпуском и количеством брака.
- `temperature_status` — статус температурного режима:
  - `normal` — температура не выше 8 °C;
  - `risk` — температура выше 8 °C;
  - `unknown` — температура отсутствует.

## Запуск проекта

Проект можно запустить двумя способами: как Python-скрипт (`main.py`) или пошагово в Jupyter Notebook (`factory_analysis.ipynb`).

### Вариант 1. Запуск Python-скрипта

1. Установить Python.
2. Установить необходимые библиотеки:

```bash
pip install pandas numpy
```

3. Разместить `main.py` и три исходных CSV-файла в одной директории.
4. Запустить скрипт:

```bash
python main.py
```

После выполнения скрипта в директории должны сформироваться три выходных файла: `factory.csv`, `suspicious_rows.csv` и `data_quality_report.csv`.

### Вариант 2. Запуск Jupyter Notebook

1. Установить Python и необходимые библиотеки:

```bash
pip install pandas numpy notebook
```

2. Разместить `factory_analysis.ipynb` и три исходных CSV-файла в одной директории.
3. Запустить Jupyter:

```bash
jupyter notebook
```

4. Открыть `factory_analysis.ipynb` и выполнить ячейки сверху вниз. Ноутбук повторяет этапы обработки из `main.py` и сопровождает их текстовыми заголовками. Выходные CSV-файлы формируются после выполнения соответствующих ячеек.
